# Flutter Developer Portfolio

Premium personal portfolio built with Next.js App Router, React 19, TypeScript, Tailwind CSS, Framer Motion, GSAP, and Lenis.

## Getting Started

```bash
npm install
cp .env.example .env.local
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Customize

1. Update personal content in `src/constants/site.ts`
2. Replace resume at `public/resume/Sachin_Choudhary_Flutter_Resume.pdf`
3. Add EmailJS keys in `.env.local`
4. Set `NEXT_PUBLIC_SITE_URL` and `NEXT_PUBLIC_GITHUB_USERNAME`

## Scripts

- `npm run dev` — development server
- `npm run build` — production build
- `npm run start` — start production server
- `npm run lint` — ESLint
- `npm run format` — Prettier

## Features

- Sticky glass navbar, mobile drawer, theme toggle
- Hero typing animation, particles, magnetic CTAs
- Projects filter + detailed modal case studies
- EmailJS contact form with validation & toasts
- Command palette (`Ctrl/Cmd + K`)
- Custom cursor, scroll progress, Lenis smooth scroll
- SEO: metadata, sitemap, robots, Open Graph, Twitter cards
- Vercel Analytics

## Stack

Next.js · React · TypeScript · Tailwind CSS · Framer Motion · GSAP · Lenis · EmailJS · shadcn-style UI
